# Mobile-first MVP

## Type

Decision

## Summary

The MyFinance MVP is a responsive web application designed first for everyday phone use. Larger breakpoints may add space and density, but must not hide or replace core mobile flows.

## Evidence

- `_bmad-output/planning-artifacts/briefs/brief-myfinance-2026-09-13/brief.md`
- Owner direction on 2026-09-13.

## Consequence

Design the authentication, account, transaction, and card flows for one-handed touch interaction and narrow screens before adding desktop enhancements. A native application is not part of this delivery.
